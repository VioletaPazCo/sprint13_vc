## 📌 Descripción del Proyecto
Cuadro de mando e infraestructura de gobernanza B2G para la red de recarga de vehículos eléctricos **Endolla Barcelona**. Este proyecto procesa y audita datos operacionales para mejorar la visibilidad de la red y la toma de decisiones.

## 🛠️ Tecnologías Utilizadas
* **Python** (Pandas, NumPy, PyArrow)
* **Visualización:** Plotly, Folium
* **Despliegue:** Streamlit Community Cloud
* **Arquitectura de Datos:** Medallion Pipeline (Bronze, Silver, Gold)
